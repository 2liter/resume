專案經驗

01

RealCam ISP Tuning Tool 開發

開發完整的 ISP 調整工具 UI，涵蓋曝光控制、白平衡、鏡頭校正、噪聲抑制、動態範圍壓縮、色調調整、邊緣增強、畸變校正等功能。並設計 IQ Table (Protobuf) 管理系统，支持 Save/Load、Combine/Separate、批次更新等功能。

C++ MFC Protobuf ISP Tuning
02

ISP Simulator 開發

針對 5M 以上高解析度影像在 RAW Domain 計算問題進行研究。導入 OpenMP 平行化，撰寫技術文件於 Confluence。使用 SIMD 指令集 (SSE/AVX) 加速 3DNR 演算法，大幅提升效能。並開發 Linux 版 IPCam Simulator。

C/C++ OpenMP SIMD Linux
03

FW 自動化測試工具

開發 MFC TrayIcon 背景執行自動測試工具，支援多種測試項目：影片錄製檢查、多解析度播放、自對焦檢測、PPWB 辨識、ESD Recovery、MIPI 時序判斷、影像檢測等，大幅減少人工測試時間。

C++ MFC UVC MIPI
04

Windows DMFT / RealSight

基於 Windows Device Media Foundation Transform (DMFT) 開發 AI 功能相機軟體 RealSight。實現 Background Blur、Face Track 功能，修復 Win11 相容性問題，完成 WHQL 測試認證，並持續支援 VAIO、HP HDR Dynamic 等 OEM 需求。

C++ DMFT WinRT WHQL
05

VideoNoiseSorter 工具

為多家 OEM 客戶開發影像品質排序工具。實現 AVC 格式影像雜訊自動檢測排序、 Sensor Test Mode 控制流程、新增 Noise Model Calibration Tool (3915 NM 微調) 等功能。

C++ 影像處理 OEM
06

AI Camera API (RtkAiCameraApi)

開發 Realtek AI Camera 對外 API，整合 HPD (Human Presence Detection) AI 功能。實現 HP Vision AI Protocol (v1~v7)，支援 Face ID、ALS via USB HID。開發 RtkHPDService 整合 DFU、Read/Register、YouTube Tag 功能。並支援 XAML/WinUI 預覽、KWS (Keyword Spotting)、Virtual Camera Driver 等。

C++ C# WinUI 3 OpenSSL DFU
07

FW CheckList / AutoTest 自動化

開發 Registry 自動檢測 FW CheckList 工具、USB Viewer、Suspend 電流檢測、Unknown Device 排查流程、新增 Execution Time 測試、Lenovo Sensor Suspend Issue 排查等自動化功能。

C++ Registry USB 自動化
08

AmebaPro2 / AmebaPro3 支援

支援 AmebaPro2/Pro3 平台 RealCam 工具移轉，包括 AIQ、RNR Calibration Tool、Long/Short Frame 擷取、RTS3917 全套 RealCam 支援 (30+ 功能)、Proto 功能擴展、Command Error Code 更新等。

AmebaPro2 AmebaPro3 RealCam
